Sets the eye texture of the executing vampire player (`vampirism:eye<type>`).

## Syntax

```
/vampirism appearance eye <type>
```

## Arguments

| Parameter | Type      | Description                  |
|:----------|:----------|:-----------------------------|
| type      | `Integer` | The eye texture id (0 to 16) |

## Permissions

:::info

Available to everyone

:::
