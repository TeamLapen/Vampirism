sidebar_position: 6

Shows the faction, level and lord level of a player.

## Syntax

```
/factions faction get <player>
```

## Arguments

| Parameter | Type              | Description                   |
|:----------|:------------------|:------------------------------|
| player    | `player_selector` | A single player target selector |

## Permissions

:::info

Requires permission level 2 (gamemaster/cheats)

:::
