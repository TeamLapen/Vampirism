## Capture

Captures the nearby village for the given faction.

```
/factions village capture <faction>
```

| Parameter | Type      | Description                            |
|:----------|:----------|:---------------------------------------|
| faction   | `faction` | The faction to capture the village for |

## Abort

Aborts a running capture process at the totem near you.

```
/factions village abort
```

## Permissions

:::info

Requires permission level 2 (gamemaster/cheats)

:::
