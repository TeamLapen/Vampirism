Turns players into [Dracula](../dracula/intro.md) (vampire faction) or the Marshall (hunter faction). If no players are given, the command is executed on you.

## Syntax

```
/factions faction set vampirism:vampire dracula [<players>]
/factions faction set vampirism:hunter marshall [<players>]
```

## Arguments

| Parameter | Type              | Description              |
|:----------|:------------------|:-------------------------|
| players   | `player_selector` | A player target selector. If not given, the command is executed on you |

## Permissions

:::info

Requires permission level 2 (gamemaster/cheats)

:::
