Sets the blood charge or the training of the vampire sword held in the main hand. If no players are given, the command is executed on you.

## Syntax

```
/vampirism sword charge <charge_amount> [<players>]
/vampirism sword trained <train_amount> [<players>]
```

## Arguments

| Parameter     | Type              | Description                     |
|:--------------|:------------------|:--------------------------------|
| charge_amount | `float`           | The sword charge (0.0 to 1.0)   |
| train_amount  | `float`           | The sword training (0.0 to 1.0) |
| players   | `player_selector` | A player target selector. If not given, the command is executed on you |

## Permissions

:::info

Requires permission level 2 (gamemaster/cheats)

:::
