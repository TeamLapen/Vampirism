Sets the gender used for your lord title.

## Syntax

```
/factions customization gender <gender>
```

## Arguments

| Parameter | Type   | Description                                       |
|:----------|:-------|:--------------------------------------------------|
| gender    | `enum` | `unknown`, `male` or `female` (use autocomplete) |

## Permissions

:::info

Available to everyone

:::
