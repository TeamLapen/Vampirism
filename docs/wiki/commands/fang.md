Sets the fang texture of the executing vampire player (`vampirism:fang<type>`).

## Syntax

```
/vampirism appearance fang <type>
```

## Arguments

| Parameter | Type      | Description                 |
|:----------|:----------|:----------------------------|
| type      | `Integer` | The fang texture id (0 to 6) |

## Permissions

:::info

Available to everyone

:::
