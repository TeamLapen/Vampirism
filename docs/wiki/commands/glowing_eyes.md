---
title: Glowing Eyes
sidebar_position: 2
---

:::caution

This command is deprecated in the mod.

:::

Enables or disables glowing eyes for the executing vampire player.

## Syntax

```
/vampirism appearance glowingEye <on>
```

## Arguments

| Parameter | Type      | Description                         |
|:----------|:----------|:------------------------------------|
| on        | `boolean` | Whether the eyes should glow or not |

## Permissions

:::info

Available to everyone

:::
