---
title: Reset Actions
sidebar_position: 10
---

Resets action duration and cooldown of players. If no players are given, the command is executed on you.

## Syntax

```
/factions actions reset [<players>]
```

## Arguments

| Parameter | Type              | Description              |
|:----------|:------------------|:-------------------------|
| players   | `player_selector` | A player target selector. If not given, the command is executed on you |

## Permissions

:::info

Requires permission level 3 (admin)

:::
